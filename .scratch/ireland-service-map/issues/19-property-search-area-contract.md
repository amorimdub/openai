## Question

Settle the human-facing outbound home-search contract after the feasibility research: which providers to offer, how to map selected or recommended towns/counties to verified provider locations, and what to show when a selected geometry or filter cannot transfer exactly. For a location without an exact match, should the user choose a broader county or finish location selection on the provider? Multiple assessed areas, unsupported budget values and a search open to anywhere need explicit behavior. Keep school/hospital/transport/utility assessment criteria within this app; send only supported housing filters. MyHome deep links require permission under its published terms, so the default research recommendation is Daft with Property.ie as an alternative and a MyHome homepage link only.

No implementation is authorized by this decision ticket. The user requested feasibility research; record human answers before resolving this ticket.
