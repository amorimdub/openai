## Gates deliberately left for later

- Latest RTB Q1 2026 report and restrictive website XLSX files were **not downloaded**; openly licensed CSO RIQ02 is acquired, with its older period explicit. Historical rent/sale observations do not represent current advertised stock or vacancies.
- An earlier RIQ02 catalogue resource UUID returned HTTP 404. The failed fetch remains in its manifest with `resolved_by`/`superseded_by` pointing to the successful, original CKAN package response. Current catalogue JSON-stat resource UUID is `a17bc386-ec5e-4ba7-93dd-bbf764fb59d9`.
- GTFS calendar validity, operators/route coverage, stop accessibility, frequency and journey-time computation are unparsed. NaPTAN and GTFS stop populations differ. Cross-border records may occur in national source lists and remain untouched.
- Sport Ireland venues/clubs are static directory records, not real-time sessions, opening status, booking availability or membership vacancies. OSM shops/green areas require later tag filtering and Republic boundary clipping; mapped absence is not evidence of real-world absence.
- PPR properties do not reliably supply bedrooms or separate house/apartment classes. Null/suppressed rent cells and geography joins must be handled during subsequent analysis. See the companion [budget and quality-of-life research](ireland-budget-quality-of-life.md) and [transport/location research](ireland-transport-location.md) for metric limitations.

## Repeat collection and verification

Repository-relative helpers are preserved at `.scratch/ireland-service-map/collectors/market_transport_qol.py` and `.scratch/ireland-service-map/collectors/verify_market_transport_qol.py`. Both accept `--date YYYY-MM-DD` and default to the current UTC date. Collection uses public read-only endpoints; verification reads source bodies but writes only manifests. A repeated date currently overwrites the previous snapshot, so use a fresh date directory or preserve the original before refetching.

```sh
python3 .scratch/ireland-service-map/collectors/market_transport_qol.py --date 2026-10-04
python3 .scratch/ireland-service-map/collectors/verify_market_transport_qol.py --date 2026-10-04
```

The collector passes the literal `$FILE` PPR URL directly to the HTTP client, avoiding shell interpolation. ZIP CRC, JSON-stat class/vector checks, pagination count/unique-ID stability, byte/SHA-256 checks, and publisher PBF MD5 checks are complete. Any future HTTP Content-Length mismatch, local hash mismatch, malformed dataset response, pagination instability or publisher-MD5 mismatch is explicitly reported as `acquisition_complete=false`.
